# NotePlan Clone 2.0

전수 점검(보안·데이터·에디터·캘린더·UI)에서 나온 문제를 고치고 화면을 다시 다듬은 버전.

## 배포 후 한 번 해야 하는 일 (Supabase)

앱은 아래를 하기 전에도 그대로 동작한다. 보안을 마저 닫으려면 실행한다.

1. **SQL Editor** 에서 차례로 실행
   - `supabase/migrations/20261005_notes_folders_rls.sql` — 노트·폴더를 '본인 것만' 보이게 (RLS)
   - `supabase/migrations/20261005_google_tokens.sql` — 구글 refresh token 을 서버에 보관
   - 확인: 파일 위쪽 주석의 확인 쿼리 두 개
2. **Edge Function 재배포**
   ```bash
   supabase functions deploy google-token-refresh
   # 웹을 vercel.app 말고 다른 도메인에서 쓰면:
   supabase secrets set ALLOWED_ORIGINS="https://내-도메인"
   ```

## 무엇이 바뀌었나

### 보안
- notes/folders RLS 를 저장소에 명시 (다른 사용자의 노트 조회·수정·가로채기 차단, PostgreSQL 16 에서 검증)
- 구글 토큰 갱신 함수가 로그인 세션을 확인 (예전엔 공개 anon 키로 누구나 호출 가능)
- 구글 refresh token 을 브라우저에 두지 않고 서버에 보관 — 새 기기에서도 재연결 불필요
- 데스크톱 앱 CSP, 웹 보안 헤더, 딥링크 위조 방지, 사이드바 실시간 구독 범위 제한, 의존성 취약점 0

### 데이터 (쓴 내용이 사라지던 경우 전부)
- 저장 충돌 시 이 기기 내용을 버리던 것 → 줄 단위로 합침, 같은 줄 충돌만 이 기기 쪽 유지(다른 쪽은 버전 기록)
- 열어보기만 해도 저장되던 것, 노트를 바꾸면 마지막 2초가 사라지던 것, 이름을 바꿔도 되돌아가던 것
- 오프라인·저장 실패 자동 재시도, 앱을 닫아도 기기에 임시 보관 후 다음에 복원
- ⌘S 가 처음 연 내용을 저장하던 것
- 폴더 이름 변경·삭제 시 안의 노트가 사라져 보이던 것
- 1000개 넘는 노트가 목록·검색·링크에서 잘리던 것, 가져오기 날짜 키 오류

### 에디터
- 본문이 늘 고정폭 글꼴로 나오던 것 → 테마 글꼴 + Pretendard(번들)
- 표: 문서 끝 타이핑이 맨 위로 튀던 것, 한글 입력 중복, 위치 어긋남
- 빈 목록 항목에서 Enter 로 목록 끝내기, 붙여넣기 오작동, 태그 오탐(#fff, foo#bar, 코드 안)
- 외부 변경이 커서를 맨 위로 보내고 ⌘Z 에 섞이던 것
- 체크박스 접근성, ⌘↩ 로 할 일 체크

### 캘린더·타임라인
- 토큰 만료 시 일정 추가가 말없이 실패하던 것 → 즉시 갱신 후 재시도, 실패하면 이유 표시
- 겹치는 일정 나란히 배치, 자정 넘는 일정, 종일 일정(한국 시간) 생성 실패, 24:00 넘는 끝 시각
- 읽기 전용 캘린더 일정은 옮기기·삭제 불가, 거절한 일정 흐리게 + 알림 제외
- 타임블록 ↔ 구글 일정 연결이 끊겨 유령 일정이 남던 것
- 타임블록 이동을 포인터 방식으로 (데스크톱 앱에서 안 되던 드래그)
- 알림이 타임라인을 열어 둘 때만 오던 것
- **빈 칸을 눌러 '할 일'(타임블록) 바로 만들기** — 모바일에서도

### 화면
- 머리줄: 날짜가 두 번 보이던 것 정리, ‹ › 와 Today 로 이동 (⌥⌘← → , ⌥⌘T)
- 사이드바 접기/펴기 (⌘\\, 캘린더 ⌘⇧\\), 크기·상태 기억, This Week, 새 노트 ⌘N
- **Review 탭**: 지난 30일 남은 할 일을 모아 체크하거나 오늘로 옮기기
- 테마 'System' (기기 라이트/다크 따라감, 새 사용자 기본값)
- 모바일: 머리줄 한 줄로, 서랍 불투명, 터치 영역 확대
- 저장 상태 표시(저장 중/저장됨/오프라인)
